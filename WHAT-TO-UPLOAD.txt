NXONE - CONTRACTS, BUDGET FIX, NO GST, SIGN IN, DASHES
=====================================================

78 files. 932 app tests, 104 server tests, build clean, every change checked
in a browser.

  cd /workspaces/nxone
  unzip -q nxone-fixes.zip
  cp -r nxone-fixes/. .
  rm -rf nxone-fixes nxone-fixes.zip
  npm test && npm run build
  git add -A && git commit -m "Contracts, budget fix, No GST, sign in, hyphens" && git push
  npx wrangler deploy

Site only. The API does not need redeploying.

JOBS ARE NOW CONTRACTS
  Every label a person sees. The page is /contracts; /jobs forwards there so
  an old bookmark still lands. Stored data keeps its field names, so nothing
  already tagged is lost.

THE EMPTY BUDGET PAGE
  "Start from what you spent last year" did nothing for a business with no
  last year - every new one. It now uses last year if there is one, otherwise
  this year's spending scaled to a full year, otherwise a blank budget, and
  says which. With no business set up, the page says so instead of going blank.

NO GST
  A "Charge GST on this ..." switch on every document. Off: no GST on any line,
  and an invoice is titled Invoice rather than Tax Invoice. Switched off in one
  place, the totals, so no line can carry GST onto a no-GST document; ticking
  it again restores each line's rate. New documents start from your scheme:
  set "Not registered for GST" on the GST scheme screen and they begin with GST
  off. That option previously did nothing. The GST return and input credit
  screens now tell an unregistered business they don't apply.

SIGN IN
  Beside "Create an invoice" in the header, on every public page including
  the home page.

DASHES
  Every em dash on the site is now a hyphen: 190 across 67 files. One remains
  inside the PDF library's character table, which maps glyphs for printing and
  is never shown.
